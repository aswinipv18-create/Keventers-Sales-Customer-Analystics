# Waffles & Milkshakes Sales Dashboard | Power BI

## Project Overview
This project analyzes sales, products, stores, customers and monthly trends
for Waffles & Milkshakes outlets using Power BI.

## Objectives
- Monitor total sales, orders and average order value.
- Identify top-selling products, categories and flavours.
- Compare store and city performance.
- Understand customer mix by type, gender and age group.
- Track monthly sales trends.

## Tools Used
- Power BI
- Microsoft Excel
- DAX
- Power Query

## Dashboard Features
- KPI cards for key business metrics
- Date range slicer (01-01-2026 to 31-08-2026)
- Page navigation buttons
- Interactive charts, tables and drill-downs

## Dashboard Pages
1. Overview (Sales Dashboard)
2. Product Analysis
3. Store Analysis
4. Customer Analysis
5. Monthly Trends

## Key Insights
- Total sales of ₹137K from 300 orders and 200 customers; average order value is ₹457.97.
- Waffles are the top category (39% of sales), followed by Milkshakes (27%), Sundae (23%) and Ice Cream (11%).
- Nutella Shake is the top product (₹7,080), followed by Nutella Waffle (₹4,350) and Red Velvet Shake (₹4,010).
- Chennai is the best-performing city with ₹45.9K (33.4% of sales), followed by Bangalore (19.6%).
- Sales peaked in March and April (about ₹23K each) and dipped in July (about ₹10K).
- Customer mix is balanced: Regular 35%, New 33%, Premium 32%; gender split is 50/50.
- Age groups 18-25, 26-35 and 36-45 contribute almost equally.
